## ✨ 핵심 기능 요약

### 1. 역할 및 권한 체계
- **관리자 (목사님, 서기)**
  - **출석 통계 대시보드**: 주차별 1부/2부 및 목장별 출석 인원, 전체 출석 인원, 출석률 프로그레스바 집계
  - **목장(반) 관리**: 연도별 반을 빈 명단부터 생성하고 신규 목장 추가, 이름/순서 수정, 삭제
  - **선생님 관리**: 각 반 선생님 계정 생성/관리 및 목장 배정
  - **체크 항목 & 달란트 설정**: 성경읽기, 대표기도 등 체크박스 컬럼 동적 추가/삭제, 각 항목별 지급할 달란트 점수 설정 (예: 출석 2점, 성경읽기 3점, 대표기도 5점 등)
  - **월별 달란트 합계 및 랭킹**: 매달 학생별/목장별 달란트 자동 집계, 1위 달란트 왕 및 **엑셀(XLSX) 다운로드** 지원
  - **마감 잠금 해제**: 반 선생님이 제출한 출석부를 수정해야 할 경우 언제든 잠금 해제 가능
  - **연도별 관리**: 매년 새해마다 새 연도(예: 2027년) 출석부를 개설하고 원하는 경우 반 이름과 순서만 복사

- **반 선생님**
  - **세션 자동 유지**: 한번 로그인하면 브라우저/앱을 닫아도 로그인 상태가 유지됩니다.
  - **전용 목장 출석부**: 로그인 시 본인이 맡은 반의 출석부만 안전하게 접근
  - **학생 관리**: 반 학생 등록, 수정, 삭제 (이름, 학년, 성별, 생년월일, 연락처, 부모님 연락처, 비고)
  - **실시간 자동 저장 체크박스**: 출석, 성경읽기, 대표기도 등 체크박스 클릭 시 **즉시 DB에 자동 저장** (저장 중/저장 완료 인디케이터 제공)
  - **오늘의 달란트 자동 계산**: 체크박스 클릭 시 설정된 달란트가 학생별로 실시간 계산되어 표시
  - **출석 제출하기 (읽기모드 잠금)**: 당일 출석 작성을 마치고 제출 버튼을 누르면 읽기 전용으로 잠겨 실수를 방지하고 축하 컨페티 효과 발생

## 📱 웹앱(PWA) 설치 방법

로그인 화면에 **설치** 버튼이 보이면 눌러 브라우저의 설치 창을 엽니다. 모바일에서 설치 버튼이 보이지 않으면 아래 경로를 따라 주세요.

| 기기 | 브라우저 | 설치 방법 |
| --- | --- | --- |
| iPhone·iPad | Safari | **공유 → 홈 화면에 추가 → 추가**. **웹 앱으로 열기** 옵션이 보이면 켜세요. 공유 버튼이 안 보이면 Safari 페이지 메뉴에서 찾으세요. |
| iPhone·iPad | Chrome | **주소창 오른쪽 공유 → 홈 화면에 추가 → 추가**. 메뉴에 없으면 Safari에서 링크를 여세요. |
| iPhone·iPad | 기타 브라우저 | 공유 메뉴에서 **홈 화면에 추가**를 찾으세요. 메뉴에 없으면 Safari에서 링크를 여세요. |
| Android | Chrome | **메뉴(⋮) → 앱 설치** 또는 **홈 화면에 추가**를 선택하세요. |
| Android | 삼성 인터넷 | 주소창의 **`+`** 버튼을 누르거나 **메뉴(☰) → 페이지 추가 → 홈 화면**을 선택하세요. |
| Android | 기타 브라우저 | 메뉴에서 **앱 설치** 또는 **홈 화면에 추가**를 찾으세요. 메뉴에 없으면 Chrome이나 삼성 인터넷에서 링크를 여세요. |
| 모바일 | 카카오톡·인스타그램 등 인앱 브라우저 | iPhone·iPad는 Safari, Android는 Chrome이나 삼성 인터넷에서 링크를 열고 위 절차를 따르세요. |
| PC | 설치를 지원하는 브라우저 | 로그인 화면에 **설치** 버튼이 표시되면 눌러 설치하세요. |

설치 후 홈 화면의 **소년부 출석부** 아이콘으로 실행하세요. 앱 모드에서 실행하면 설치 안내가 숨겨집니다.

## 로그인

Firebase Authentication에 등록된 이메일과 비밀번호를 사용합니다. 비밀번호는 DB에 저장하지 않으며 재설정 이메일로 변경합니다.

## Firebase 연결 및 운영

웹사이트는 GitHub Pages에, 공용 데이터는 Firebase Firestore에 저장합니다.

[최초 관리자 계정, Authentication, 보안 규칙 설정 안내](docs/FIREBASE_SETUP.md)를 따라 설정하세요. 관리자는 등록된 이메일로, 목장 계정은 연도·부서·목장 번호를 합친 아이디로 로그인합니다. 예: 2026년 1부 14목장 → `260114`. 체험 로그인과 공용 비밀번호는 운영에서 사용할 수 없습니다.

Firebase Spark 요금제의 Firestore 무료 한도는 **하루 문서 읽기 5만 건, 하루 문서 쓰기 2만 건, 저장 용량 1 GiB**입니다. [Firestore 공식 요금 안내](https://firebase.google.com/docs/firestore/pricing)

```
│   ├── LoginView.vue        # 로그인 화면 (원클릭 간편 프리셋 포함)

│   │   ├── AttendanceView.vue  # 출석 체크박스, 실시간 자동저장, 제출 잠금
│   │   └── StudentsView.vue    # 반 학생 등록/수정/삭제

│       ├── AdminLayout.vue     # 관리자 메뉴

│   ├── AppHeader.vue        # 상단 공통 헤더
│   ├── Modal.vue            # 공통 팝업 모달

```
